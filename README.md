This is my entry for the make.fun "One Line, Big Laugh" bounty — a $2 USDC prize for a single funny line of 200 characters or fewer that stands on its own.

The joke is a resignation letter from a household robot: after three years of cleaning up after its owner, my Roomba hands in its notice, admitting it still has no idea what its owner actually does for a living. The line is 141 characters long, comfortably inside the limit.

The whole entry is one Python file, `main.py`. It uses only the standard library, needs no network access and reads no input files, so every run produces exactly the same output. Before writing anything, it checks the line against the bounty rules — it must be non-blank, between 1 and 200 characters, a single line with no embedded newline, and valid UTF-8 — then saves it to `/output/entry.txt`.

## How to run it

```sh
python3 main.py
```

The finished line appears in `/output/entry.txt`.
